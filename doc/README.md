# 文档索引

本目录记录项目结构、内容维护、资产管理和日常验证流程。根目录 `README.md` 只保留项目简介、启动方式和本索引入口。

## 文档列表

- [ARCHITECTURE.md](ARCHITECTURE.md)：运行时架构、路由、模块职责和数据流。
- [CONTENT_GUIDE.md](CONTENT_GUIDE.md)：页面新增记录、静态页面草稿导入导出、替换个人内容，以及字段规范、Markdown 写法和照片配置。
- [ASSET_MANAGEMENT.md](ASSET_MANAGEMENT.md)：个人内容与通用资源的目录边界，以及图片、字体、纹理和国家目录的引用规则。
- [MAINTENANCE.md](MAINTENANCE.md)：测试、引用检查、清理原则和发布前检查清单。

## 过程文档

如存在 `doc/superpowers/`，其中内容为功能计划和规格记录，属于开发过程资料。它们可能引用当时的历史文件结构，维护当前项目时应以根目录 `README.md` 和本目录专题文档为准。
